# 这包到底便不便宜？

一个免费开源的日用品单位价比较工具。粘贴商品规格和到手价，核对后比较每升、每公斤或每件价格。

**无需安装、无需账号、无需 API Key。所有计算和比较记录均在当前浏览器本地完成。**

## 立即使用

下载仓库或 ZIP，双击 `index.html` 即可。也可使用任意静态文件服务器。

1. 粘贴 `全脂牛奶 250ml×24盒，券后59.9元`。
2. 点击“识别规格与价格”，核对名称、总价、单件规格和实际件数。
3. 点击“确认并加入比较”，继续添加第二款商品。
4. 查看各组最低单位价和差额。页面中的牛奶示例可以直接体验。

自动解析只填表，用户确认后才加入比较。不能识别时仍可手动填写。

## 示例

| 商品 | 包装 | 到手价 | 每升价格 |
| --- | --- | --- | --- |
| 牛奶 A | 250ml × 24盒，共6L | ¥59.90 | 约 ¥9.9833/L |
| 牛奶 B | 200ml × 24盒，共4.8L | ¥49.90 | 约 ¥10.3958/L |

牛奶 B 整箱便宜，但单位价更高。以上仅为演示数据，不是实时商品报价。

电池“6颗买6送1”的实际总件数请人工核对后填 7：单件规格填 1，单位选“件”，总价填实际支付金额。自动解析遇到买赠组合不会自行猜测。

## 功能与范围

- 支持 ml / L、g / kg，以及件、颗、粒、节；统一显示每升、每公斤或每件价格。
- 支持 `250ml×24盒`、`250ml×6盒×4提`、`500g×4袋` 等顺序规格。
- 支持券后价、到手价、实付金额，或单一“元 / ¥ / ￥”价格。
- 明确的到手价优先于原价；多个到手价、买赠、不完整规格等歧义要求手动核对。
- 比较结果按计量类型分组，不将重量与容量或件数混在一起排名。
- 提供移除、清空和浏览器本地保存，最多100款商品。
- 移动端布局、键盘操作、表单标签和状态提示。

## 使用边界

只比较价格，不比较品质、品牌或用途。请只比较可替代的同类商品。

到手价需自行计入运费，并扣除实际可使用的优惠；工具不会读取电商账号、领取优惠券、抓取价格或自动计算满减。

暂不处理 `24盒×250ml` 等倒序表达；请手动填写。不能把克与毫升直接换算。抽纸的尺寸、层数与抽数影响可比性，第一版不自动解析这些规格。

所有价格均为人民币，输入最多两位小数；计算使用 JavaScript 数值，显示最多8位有效数字，非财务结算系统。

本地存储可因浏览器限制不可用，届时页面会提示仅当前会话保存。清理浏览器数据会丢失记录；请勿把这里当永久账本。

## 开发与测试

页面没有第三方依赖，也没有构建步骤。测试需要 Node.js 20 或更新版本：

```sh
node --test tests/core.test.js
node --check app.js
```

GitHub Actions 自动检查规格解析、单位换算、价格比较、歧义拒绝和输入验证。

```
index.html        页面与表单
style.css         响应式样式
core.js           解析、验证和单位价计算
app.js            页面交互与本地保存
tests/core.test.js 核心逻辑测试
```

## 部署到 GitHub Pages

在仓库的 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。部署完成后使用 GitHub 返回的网址。

## 需求来源

[V2EX：购买电池发现的小套路](https://www.v2ex.com/t/1213348) 中，用户讨论了电池包装、牛奶容量与箱数对单位价的影响。这是本项目的场景来源，不代表已经验证市场规模或付费意愿。

欢迎提交 Issue，描述实际商品规格、预期结果和当前行为。分享截图或文本时请去掉姓名、地址、订单号等个人信息。欢迎提交修复和测试。
